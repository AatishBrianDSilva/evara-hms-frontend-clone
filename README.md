# How to deploy React APP on SST

## Getting Started

[**Read the tutorial**](https://sst.dev/docs/examples/#react-spa-with-vite)

## Commands

### `npx sst dev`

Run locally with SST.

### `npx sst deploy --stage=prod`

Deploy your app to AWS

### `npx sst remove --stage=prod`

Remove your application from AWS
